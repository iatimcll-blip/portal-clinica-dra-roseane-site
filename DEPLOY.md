# Publicacao

Este repositorio esta preparado para GitHub Pages com GitHub Actions.

1. Acesse `Settings > Pages`.
2. Em `Source`, selecione `GitHub Actions`.
3. Aguarde o workflow `Deploy static site to GitHub Pages` concluir.
