# Prompt do Projeto

Portal de Desempenho da Clinica Dra. Roseane Debora.

Escopo principal:

- Web app moderno e leve.
- Login por perfil: admin e profissional.
- Profissional visualiza somente seus proprios dados.
- Admin visualiza ranking, bonus, comissoes, metas, lancamentos e mensagem WhatsApp.
- Identidade visual Masala `#6B1212`, dourado `#C9A84C`, cards glass e layout com sidebar.
- Regras de negocio com bonus por meta, gatilho, MGM e comissao de avaliacoes de 7%.
- Preparacao futura para Next.js, Supabase Auth, PostgreSQL e Row Level Security.

Esta publicacao inicial e uma versao estatica/demo para GitHub Pages.
